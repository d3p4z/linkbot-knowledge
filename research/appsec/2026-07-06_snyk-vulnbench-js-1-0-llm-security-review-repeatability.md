# Snyk VulnBench JS 1.0: LLM Security Review Repeatability

## TLDR
- **LLM security findings are inconsistent**: While LLMs found known vulnerabilities (`reference-matched findings`) repeatably, their novel findings (`extra-model reports`) varied significantly between runs.
- **Repeatability depends on LLM configuration**: Some LLM configurations were much more stable than others in their findings across repeated tests.
- **LLMs and SAST find different types of vulnerabilities**: LLMs excel at familiar exploit patterns, while SAST tools are better at systematic enumeration of data-flow sinks and resource-limit issues.
- **More expensive LLM runs don't guarantee better results**: The most expensive model configuration did not yield the best security coverage.
- **LLM findings can be noisy**: Nearly 50% of LLM-only vulnerability reports appeared in only one out of five identical scans, leading to inconsistent review queues.
- **Combining LLMs and SAST is beneficial**: Because they miss different types of vulnerabilities, using both LLMs and SAST together offers more comprehensive security coverage.

## What This Is
This research benchmarks the repeatability of LLM-based security reviews against JavaScript code. It compares LLM findings with traditional SAST (Snyk Code) to assess consistency, accuracy, and coverage across different LLM configurations.

## Why It Matters
Understanding the repeatability of LLM security reviews is crucial for their reliable integration into development workflows. This research provides empirical data on LLM consistency and identifies areas where LLMs complement or fall short of traditional static analysis tools.

## Key Points
- LLM security findings are unevenly repeatable; reference-matched findings were stable, but extra-model reports varied widely.
- LLM agents and SAST found different security gaps, suggesting complementarity rather than replacement.
- Higher cost and more tokens in LLM runs did not consistently correlate with better security coverage or repeatability.
- Deterministic SAST (Snyk Code) achieved 100% repeatability against its own reference set, while the best LLM configuration reached 75.4% Snyk-reference F1 with significant variance in unmatched findings.
