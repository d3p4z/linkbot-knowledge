# "Dirty Frag" and other issues in Amazon Linux kernels

## What This Is
This bulletin describes a class of vulnerabilities in the Linux kernel, referred to as 'Dirty Frag,' affecting Amazon Linux. These issues allow unprivileged users to gain access to kernel memory and escalate privileges.

## Why It Matters
This is critical for application security as it highlights a kernel-level vulnerability that can be exploited by unprivileged users on affected Amazon Linux systems to gain elevated access, posing a significant risk to system integrity and data security.

## Key Points
- Vulnerabilities known as 'Dirty Frag' are present in several Linux kernel loadable modules (e.g., xfrm_user/esp4/esp6, ipcomp4/ipcomp6).
- Exploitation is possible on systems allowing unprivileged users to create sockets or user namespaces.
- An actor may gain access to kernel memory and escalate privileges.
- Mitigation involves checking for loaded modules, disabling them, or disabling module loading entirely.
- Specific mitigation for namespaces is also provided.
